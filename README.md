# 🏦 FinTech News Tracker

> 금융IT 뉴스를 자동으로 수집하고 정리

## 📌 소개

금융권 IT 취업을 준비하면서 업계 동향을 파악하기 위해 만든 자동화 도구입니다.
매일 아침 주요 경제/IT 매체에서 금융IT 관련 뉴스를 수집하여 마크다운으로 정리합니다.

## ✨ 주요 기능

- **자동 수집**: GitHub Actions로 매일 오전 7시(KST) 자동 실행
- **키워드 필터링**: 금융IT 관련 키워드로 관련 기사만 추출
- **카테고리 분류**: 인프라, 디지털금융, 보안, 금융권 동향 등으로 분류
- **마크다운 정리**: 깔끔한 형식으로 자동 문서화

## 🔍 수집 키워드

| 카테고리 | 키워드 |
|---------|--------|
| 🏗️ 금융 인프라 | 코어뱅킹, 차세대 시스템, 금융 클라우드, 레거시 전환 |
| 📱 디지털 금융 | 오픈뱅킹, 마이데이터, 핀테크, 간편결제, 모바일뱅킹 |
| ⚙️ 금융 기술 | 금융 API, 로보어드바이저, 블록체인, RPA |
| 🔒 보안/규제 | 금융보안, 전자금융, FDS, 망분리, 금융위/금감원 |
| 🏛️ 금융권 동향 | 은행 IT, 농협은행, KB국민, 신한은행, 금융결제원 |
| 🌱 ESG 금융 | 녹색금융, 탄소금융, 그린본드 |

## 🚀 사용법

### GitHub에서 자동 실행

1. 이 저장소를 Fork
2. Actions 탭에서 워크플로우 활성화
3. 매일 오전 7시(KST)에 자동 실행됨
4. 수동 실행: Actions → Daily FinTech News Update → Run workflow

## ⚙️ 커스터마이징

### 키워드 추가/수정

`src/news_collector.py`의 `KEYWORDS` 딕셔너리를 수정하세요:

```python
KEYWORDS = {
    "금융_인프라": [
        "코어뱅킹",
        "차세대",
        # 원하는 키워드 추가
    ],
    # ...
}
```

### RSS 피드 추가

`RSS_FEEDS` 딕셔너리에 새 소스를 추가하세요:

```python
RSS_FEEDS = {
    "새로운소스": "https://example.com/rss",
    # ...
}
```

### 실행 시간 변경

`.github/workflows/daily-news.yml`의 cron 표현식을 수정하세요:

```yaml
schedule:
  - cron: '0 22 * * *'  # UTC 기준, 한국시간 = UTC + 9
```
