# 🏦 FinTech News Tracker

> 금융IT 뉴스를 자동으로 수집하고 AI로 분석/정리

## 📌 소개

금융권 IT 취업을 준비하면서 업계 동향을 파악하기 위해 만든 자동화 도구입니다.

- 매일 아침 주요 경제/IT 매체에서 금융IT 관련 뉴스 수집
- **중요도 점수**로 핵심 기사 선별
- **AI 분석**으로 신문스크랩 형식 자동 정리

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🕐 자동 수집 | GitHub Actions로 매일 오전 7시(KST) 실행 |
| 🔍 키워드 필터링 | 금융IT 관련 키워드로 기사 추출 |
| 📈 중요도 분석 | 점수 기반으로 핵심 기사 TOP 5 선별 |
| 🤖 AI 분석 | Groq API로 기사 요약 및 용어 정리 |
| 📝 마크다운 정리 | 신문스크랩 형식으로 자동 문서화 |

## 📊 중요도 점수 시스템

| 기준 | 점수 |
|------|------|
| 주요 출처 (한경, 매경, 전자신문) | +3점 |
| 제목에 키워드 포함 | +3점/개 |
| 핵심 키워드 (금감원, 오픈뱅킹, 농협은행 등) | +2점/개 |
| 일반 키워드 매칭 | +1점/개 |

## 📄 출력 형식

각 기사는 다음 형식으로 정리됩니다:

```markdown
## 📋 기본 정보
| 항목 | 내용 |
|------|------|
| 날짜 | 2025.01.27 |
| 출처 | 한국경제 |
| 카테고리 | 금융규제 |

## 📝 3줄 요약
1. 첫 번째 핵심 내용
2. 두 번째 핵심 내용
3. 세 번째 핵심 내용

## 🔑 핵심 키워드
`금감원` `인지수사권` `금융규제`

## 📊 주요 내용
(구조화된 내용 정리)

## 📖 금융 용어 정리
| 용어 | 설명 |
|------|------|
| 인지수사권 | 직접 수사를 개시할 수 있는 권한 |
```

## 🚀 설정 방법

### 1. 저장소 Fork

이 저장소를 Fork 합니다.

### 2. Groq API 키 발급 (무료)

1. https://console.groq.com 접속
2. Google/GitHub 계정으로 로그인
3. API Keys → Create API Key
4. 키 복사

### 3. GitHub Secret 등록

Settings → Secrets and variables → Actions → New repository secret

| Name | Value |
|------|-------|
| `GROQ_API_KEY` | 발급받은 키 |

### 4. Actions 활성화

1. Actions 탭 → 워크플로우 활성화
2. 매일 오전 7시(KST) 자동 실행
3. 수동 실행: Run workflow 버튼
